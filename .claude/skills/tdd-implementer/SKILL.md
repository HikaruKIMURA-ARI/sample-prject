# TDD Phase 4: GREEN（最小実装）

## 手順

1. テストをパスさせる **最小限のコード** だけを書く
2. `mise run test` を実行してパスを確認する
3. 他のテストが壊れていないことを確認する

## ルール

- "最小限"とは：余分な機能、最適化、リファクタリングを含まない
- テストが要求しないエッジケース処理は追加しない
- リファクタリングはこのフェーズではしない（Phase 5 で行う）
- 全テストがパスすることを確認する
- ディレクトリ構造は `.claude/rules/architecture`を参考にし、迷う部分があればユーザーに確認をすること

## 禁止事項

- テストファイルの編集（テストの意図を変えてしまうため）
- テストが要求しない機能・エッジケース処理の追加
- パフォーマンス最適化（明確なボトルネックがある場合のみ Phase 5 で扱う）

## 出力形式

- 変更したファイルのパス
- テスト実行結果（全て PASS）
- 実装の簡潔な説明
